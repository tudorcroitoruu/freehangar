2026-11-11 memory/save follow-up
Confirmed source issue: SwitchSavePump retries once per second; previously each
retry called Store.Encode before NXSave rejected it for the 15-second write rate.
CanSave is now checked before encoding. Goal snapshot capture is throttled to at
most once per 30 seconds on Switch, coalesces requests, and cancels pending work
when a newer synchronous save occurs. Forced pause/exit saves remain immediate.
Archive version 2 encoding now streams JSON, removing the full document string
and temporary Entry list. Existing saves still round-trip. NXSave rejects writes
over the requested 32 MiB budget before resizing/replacing the existing file.
This is an application budget, not a claim of a universal Nintendo save limit.
